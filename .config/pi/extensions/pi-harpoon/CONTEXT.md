# Pi Harpoon

Pi Harpoon provides quick switching among user-curated AI model choices.

## Language

**Harpoon entry**:
A provider and model paired with an optional thinking level.
_Avoid_: Model, which does not include the optional thinking level.

**Harpoon list**:
An ordered collection of Harpoon entries chosen by the user. Its order defines the cycling sequence.
_Avoid_: Session history, which records past usage rather than curated choices.
